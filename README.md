# Book Manager

## Sprint 1

### Objetivo

Aplicar los conocimientos adquiridos en programación orientada a objetos y almacenamiento de datos en archivos para su persistencia.

### Introducción y contexto

Una librería con venta al público necesita modernizar su sistema de gestión de inventario de libros. Debido a la fluctuación en los costos de importación, el sistema gestiona precios en distintas monedas y sigue la cotización del dólar para actualizar sus valores.

Se desarrolla una aplicación de consola (CLI) en Python que permite gestionar el inventario, cotizar los libros según el valor del dólar y comparar precios con la competencia web.
